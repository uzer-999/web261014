챗지피티 활용 내용:

이번 영화 보드 웹페이지를 만들면서 챗GPT를 활용해 HTML과 CSS의 개념을 이해하고, 코드를 작성하는 과정에서 생기는 궁금증을 해결했다. 코드를 직접 만들어 달라고 요청하기보다는 flex와 grid의 차이, 미디어 쿼리가 작동하는 원리 등을 질문하며 배운 내용을 정리했다. 또한 개발자 도구에 나타나는 오류 메시지의 의미를 물어보면서 문제의 원인을 파악하는 데 도움을 받았다.

특히 화면 크기에 따라 카드의 열 수가 바뀌거나 메뉴의 배치가 달라지는 이유를 이해하는 데 챗GPT가 유용했다. 단순히 정답을 확인하는 것보다 개념을 질문하고 직접 코드를 작성한 뒤 브라우저에서 결과를 확인하는 과정이 중요하다는 것을 느꼈다. 앞으로도 나 자신의 발전을 위해 챗GPT를 코드를 대신 작성해 주는 도구가 아니라, 스스로 문제를 해결하고 웹 개발 지식을 익히는 학습 보조 도구로 활용하고 싶다.
